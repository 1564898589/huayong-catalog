南京华用电气 · 产品手册手机版 —— 使用说明
================================================

一、这是什么
------------
一个放在 GitHub Pages 上的手机网页（免费、不需要云服务器）。
外出时用手机打开网址，搜到产品，点「发微信」就能把该产品 PDF 发给客户。
当前收录：66 个产品 / 14 个分类（含 TB 系列测试模块）。
内容来源：桌面\华用\B产品资料\南京华用产品手册分页2026.9（由新合订册分页而来）。

二、手机怎么用
--------------
1. 用手机浏览器（Safari / Chrome）打开上线网址（见下方"上线网址"）。
   建议"添加到主屏幕"，以后像 App 一样一点就开。
2. 顶部搜索框输型号或名称，如 RML、防跳、温湿度；或点分类标签筛选。
3. 找到产品后：
   · 点绿色「发微信」→ 弹出手机系统分享面板 → 选微信 → 选客户 → 发送。
   · 点「预览」→ 直接在手机上看 PDF。
   · 点链接图标 → 复制该产品网址，粘贴到微信发给客户也行。
   若分享面板没出现，会自动打开 PDF，用浏览器右上角"分享/发送"菜单同样能发微信。

三、以后怎么更新内容（你自己就能做）
------------------------------------
1. 把新增/替换的 PDF 放进源文件夹的对应分类子文件夹：
   桌面\华用\B产品资料\南京华用产品手册分页2026.9\<分类>\
   （要删除某产品，就把对应 PDF 从该文件夹删掉。）
   新建分类 = 新建一个子文件夹。
2. 双击本目录里的「更新网站.cmd」。
   它会自动：重新扫描 PDF → 重建网页数据 → 提交并推送到 GitHub。
3. 等约 1 分钟，手机刷新网页即是新内容。
   首次运行会弹出浏览器让你登录 GitHub 授权，登录一次以后就不再弹。

四、本地预览（不上网也能看）
----------------------------
· 直接双击 index.html 即可在电脑浏览器打开浏览。
· 或在本目录运行：node server.js ，然后打开 http://localhost:8787

六、常见问题
------------
· 更新时提示 git 登录/推送失败：首次需登录 GitHub 并配置远程仓库，按弹窗完成即可。
· 更新后手机没变化：GitHub Pages 生效约需 1 分钟，稍等再刷新。
· github.io 在国内移动网络偶尔慢或打不开：属平台限制；如经常遇到，可改用
  Cloudflare Pages 等国内更稳的免费托管（网页文件完全通用，找我即可迁移）。
· 微信里直接打开本网页时"发微信"按钮可能不弹分享面板：请点右上角"…"选
  "在浏览器打开"，再点「发微信」；或直接复制链接发给客户。
